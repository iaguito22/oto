# Oto 音

Reproductor de música para Android sobre YouTube Music (InnerTube), sin pestañas ni botones: una gota que se maneja con gestos.

En construcción. Uso personal: se instala desde el APK, no está en Play Store.

- Kotlin · Jetpack Compose · Media3
- [InnerTubeX](https://github.com/MetrolistGroup/innertubex) para la extracción de streams
- El módulo `innertube/` viene de [Metrolist](https://github.com/MetrolistGroup/Metrolist) (GPL-3.0)

## Compilar

```sh
JAVA_HOME=/usr/lib/jvm/java-21-openjdk ./gradlew :app:assembleDebug
```
