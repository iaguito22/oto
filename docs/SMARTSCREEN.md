## ⚠️ Aviso de Windows al instalar

El instalador no lleva firma Authenticode, así que Windows SmartScreen puede mostrar
la pantalla **«Windows protegió tu PC»** al abrirlo.

Oto es software de código abierto; puedes revisar el código en este repositorio y
verificar el hash del archivo descargado con el `SHA256SUMS.txt` adjunto.

### Pasos para instalar igualmente

1. Aparece la pantalla con el texto «Windows protegió tu PC».
2. Haz clic en **Más información** (enlace gris, parte superior izquierda).
3. Aparece el botón **Ejecutar de todas formas** → haz clic.
4. El instalador de Oto abre normalmente; sigue los pasos habituales.

> El aviso desaparece si el ejecutable acumula suficientes descargas con el tiempo,
> o si se firma con un certificado Authenticode comercial.
